# Contributing to Manasitra

Thank you for your interest in improving Manasitra. We welcome contributions that maintain code hygiene, enhance mental health safety, and improve accessibility for students.

## Guidelines
1. **Safety First**: Never bypass or weaken crisis detection rules or helpline routing.
2. **Privacy**: Never introduce telemetry, PII logging, or third-party tracking scripts that compromise user anonymity.
3. **Branching**: Create feature or chore branches (e.g., `feature/improved-gujarati-prompts` or `fix/telemanas-contact-card`). Do not commit directly to `main`.
4. **Testing**: Run all unit and integration tests before submitting PRs:
   ```bash
   cd backend && npm test
   ```
5. **Code Style**: Follow the configured `.editorconfig` rules (2 spaces, LF line endings, UTF-8).
